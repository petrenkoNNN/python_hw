Название: Анализ цен и локаций недвижимости

Автор / псевдоним: Петренко Надежда

Что делает программа: консольная программа на Python 3. Хранит небольшую «базу» объектов недвижимости (список словарей: id, название, цена, расстояние до центра). В меню можно: 1 - найти объекты не дальше заданного расстояния до центра, 2 - сравнить цену выбранного объекта со средней по базе (на сколько процентов дороже или дешевле), 0 - выйти. Программа нужна человеку, который выбирает жильё и хочет быстро сравнить цену и удалённость от центра.

Как запустить: python main.py (нужен Python 3, внешние библиотеки не требуются).

Проверка 1 (обычная):

Вход: пункт 1, расстояние 5; затем пункт 2, ID 4.
Ожидание: найдены «Квартира в центре» и «Студия у метро»; средняя цена 8450000.0 руб., «Дом с участком» дороже средней на 65.68 %.
Результат: совпало с ожиданием.

Проверка 2 (необычная / граничная):

Вход: пункт 1, расстояние 0.5; затем abc; затем пункт 2, ID 99.
Ожидание: «Объектов в такой локации не найдено.»; «Ошибка: введите число!»; «Объект с таким ID не найден!». Программа не падает. Граница включается (при 3.5 находятся объекты 1.2 и 3.5 км), а calculate_price_difference(1000000, 0) даёт 0.0 без деления на ноль.
Результат: совпало с ожиданием.
